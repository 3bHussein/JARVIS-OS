JARVIS OS · DESKTOP PREVIEW

Your workspace, in its own window.

The local built service is not ready. This native host never starts processes or reads your password/configuration.

  1. Run 01-Setup-JARVIS.bat once.
  2. Run 02-Start-JARVIS.bat and keep its terminal open.
  3. Choose Open local workspace from this window's native menu.
  4. Unlock with your existing local password. Browser and desktop sessions are separate.

مساحة جارفس بنافذة مستقلة

خدمة جارفس المحلية لسه مش جاهزة. شغّل ملف 02 وسيب الترمينال مفتوح، وبعدها اختار «افتح مساحة العمل» من قائمة النافذة. نافذة سطح المكتب مش بتقرأ الباسورد أو بتشغّل أوامر نظام.

احفظ بيانات جلستك مشفّرة قبل الانتقال من المتصفح؛ الجلسات والملفات المستوردة مش بتتنقل تلقائيًا.

Node24+ and the existing local runtime are still required. This is not a bundled-runtime installer. External/new-window links are blocked in this first host; use browser mode for original app launches. Voice, microphone, download and notification behavior need actual WebView2 device testing.
